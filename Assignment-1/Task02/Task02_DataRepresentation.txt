TASK 2 – CHOOSE THE DATA REPRESENTATION

1. Data Types Used

Slot Number:
Data Type: int
Reason: Slot numbers are whole numbers.

Vehicle Number:
Data Type: String
Reason: Vehicle registration numbers contain both letters and numbers, for example TN01AB1234.

Entry Time:
Data Type: long
Reason: The system can store the entry time in milliseconds.

Parking Duration:
Data Type: int
Reason: Parking duration can be calculated in whole minutes.

Parking Fee:
Data Type: double
Reason: Parking fees may contain decimal values.

Ticket Number:
Data Type: int
Reason: A ticket number is a unique whole number generated by the system.

2. Array Structure

The parking slots are represented using a two-dimensional jagged array:

String[][] slots;

The first index represents the floor and the second index represents the parking slot.

Example:

slots[0][0] represents the first slot on the first floor.

A jagged array is useful because different floors can have different numbers of parking slots.

3. Input Method

The Scanner class can be used to read input from the user.

Example:

Scanner scanner = new Scanner(System.in);

The user can enter the vehicle number and vehicle type through the keyboard.

4. Integer Division and Casting Risk

An incorrect calculation can occur when integer division is used.

For example:

int minutes = 90;
int hours = minutes / 60;

The result will be 1 because integer division removes the decimal part.

However, if every started hour must be charged, 90 minutes should be charged as 2 hours.

The correct calculation is:

int hours = (minutes + 59) / 60;

This calculates the ceiling value using integer arithmetic.

5. Alternative Data Representation

The slots can also be stored in a one-dimensional array using the formula:

index = floor * slotsPerFloor + slot;

However, this approach works best when every floor has the same number of slots.

If floors have different numbers of slots, a jagged two-dimensional array is easier to manage.

Time Complexity:

Locating a slot using direct indexes takes O(1) time in both representations.

Space Complexity:

Both representations require O(n) space for n total parking slots. A jagged array is more flexible when different floors have different numbers of slots.
