DESIGN EVALUATION

The system uses separate classes and methods to organize parking tickets, slot allocation and fee calculation. A HashMap is used to find active tickets using the vehicle registration number efficiently.

The design handles normal, boundary and invalid cases. The system can be extended by adding new vehicle types and parking rules.
